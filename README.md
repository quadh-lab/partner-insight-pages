# 파트너센터 인사이트 (팀 대시보드)

파트너센터 판매 현황을 분석하는 단일 파일 대시보드. 서버 없이 GitHub Pages에서 동작합니다.

## 구성
- `index.html` — 대시보드 앱 (데이터 없음)
- `data.enc.json` — 비밀번호로 AES-GCM 암호화된 팀 데이터 (관리자가 생성해 업로드)

## 팀원 사용법
배포 주소에 접속 → 비밀번호 입력 → 대시보드가 브라우저 안에서 복호화되어 표시됩니다.
저장소가 공개여도 비밀번호 없이는 데이터를 읽을 수 없습니다.

## 관리자: 데이터 갱신
1. 로컬 마스터 파일(partner-insight.html)을 열어 실시간 현황 붙여넣기 / 정산 엑셀 업로드로 데이터를 갱신
2. '데이터 관리' 탭 → **팀 공유 (암호화 배포)** → 비밀번호 입력 → `data.enc.json` 내려받기
3. 저장소의 `data.enc.json`을 새 파일로 교체(같은 이름으로 업로드)

비밀번호를 바꾸려면 새 비밀번호로 다시 내려받아 교체하면 됩니다.

## 주의
- `data.enc.json`이 없으면 페이지는 개인용(브라우저 저장) 모드로 동작합니다.
- 팀 모드에서 화면상의 변경은 각자 브라우저에만 머뭅니다 — 공유 원본은 항상 `data.enc.json`입니다.
